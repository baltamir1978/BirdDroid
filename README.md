# BirdDroid

Identifica aves por su canto y por foto, con todos los modelos ejecutándose en el móvil.

Versión para Android de [BirdApp](https://github.com/baltamir1978/BirdApp), la app de iOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Kotlin + Jetpack Compose, para **Android 12 o posterior**, también en **GrapheneOS** (sin los servicios de Google).
